# 🎙️ Lafza: AI-Powered Diction & Pronunciation Coach

Lafza is an AI-powered Android application designed to help users improve their diction, elocution, and pronunciation by reading challenging tongue twisters. The app analyzes the user's voice in real-time, detects swallowed letters or mispronounced words, and provides instant scoring and feedback.

### 🎥 Watch the Promo Video
[![Lafza Promo Video](https://img.youtube.com/vi/zDZtLMvu0ec/0.jpg)](https://youtube.com/shorts/zDZtLMvu0ec)

## 🚀 Features
* **AI-Powered Voice Analysis:** Real-time speech recognition and precise error detection.
* **Extensive Twister Archive:** Carefully curated exercises across various difficulty levels (A1 - C2).
* **Detailed Scoring & Badge System:** Achievement badges based on performance and statistical progress tracking.
* **Daily Streak System:** Gamified approach to encourage daily practice and maintain reading streaks.
* **Premium (In-App Purchases):** Google Play Billing integration for unlimited reading and access to locked "Pro Stages".
* **Dark/Light Theme:** Modern, responsive, and user-friendly UI.

## 🛠️ Tech Stack & Architecture
This project is built following modern Android development standards and Clean Architecture principles:

* **Language:** Kotlin
* **User Interface (UI):** Jetpack Compose, Material Design 3
* **Architecture:** MVVM (Model-View-ViewModel)
* **State Management:** StateFlow & ViewModel
* **Asynchrony:** Kotlin Coroutines
* **Analytics & Monitoring:** Firebase Analytics & Firebase Crashlytics
* **Monetization:** Google Play Billing Library
* **Local Storage:** SharedPreferences
